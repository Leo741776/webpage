Real-Time Stepper Motor Control System

I built a real-time stepper motor control system using an STM32C031C6, FreeRTOS, and an A4988 driver to control a NEMA 17 motor. The system uses separate RTOS tasks for motor control, safety monitoring, and user input/display instead of relying on a single blocking loop. Motor speed, direction, and microstepping can be adjusted through physical buttons, while an ST7735 TFT displays the current settings.

A hardware timer handles the step pulses independently from the RTOS scheduler, allowing precise and consistent motor timing. I also implemented software acceleration ramping to smoothly change motor speed and an interrupt-driven emergency stop that can immediately halt the motor.

Different tools and techniques were used to make this program, such as FreeRTOS task scheduling, queues, mutexes, interrupts, hardware timers, SPI, and GPIO.

Air Quality Monitoring System

In order to challenge myself to write embedded firmware without the use of an abstraction layer, I built register-level drivers from scratch. This allowed me to gain complete control over the hardware while keeping memory overhead minimal and performance snappy.

The project brings together a few different environmental sensors: a PMS5003 for particulate matter via UART, an SCD40 for CO2 and temperature/humidity via I2C, and an SGP40 for VOC readings, all driven by manually configured UART, I2C, SPI, GPIO, and SysTick modules. To keep things robust against messy sensor data, I added frame header synchronization and CRC checksum validation to catch corrupted packets before they hit the display.

Everything is organized modularly with a clean separation between low-level drivers, data sharing, and the UI pipeline, rendering live metrics cleanly onto an ST7735 display via SPI.

Embedded 3D Raycasting Engine

I am interested in computer graphics and also wanted to write a program that could run on limited hardware, and that led me to building a real-time raycasting engine for an STM32 microcontroller. Since the chip lacks a hardware floating-point unit, I used the DDA algorithm with Q16.16 fixed-point arithmetic and precomputed trigonometric lookup tables. The engine outputs graphics to an ST7735 display over SPI.

I organized the program into modular files (dda.c, player.c, map.c, and draw.c) for collision detection, camera rotation, and directional shading. I also built a cross-platform desktop companion version using SDL3 to experiment with higher resolutions and frame rates.

Multithreaded HTTP Server

To learn more about network programming and concurrency, I built a multithreaded HTTP server in C++ using Winsock. Instead of creating a new thread for each connection, I implemented a worker-thread pool to handle multiple clients concurrently. I also implemented TCP socket setup, client connection management, HTTP request parsing and routing, and static file serving.

I tested the server with a PowerShell-based stress test that sent 10 waves of 50 concurrent requests. The server successfully handled all 500 requests without crashes.
