Projects

Embedded Air Quality Monitor

In order to challenge myself to write embedded firmware without relying on the hardware abstraction layer (HAL), I built custom, register-level drivers from scratch. This allowed me to gain complete control over the hardware while keeping memory overhead minimal and performance snappy.

The project brings together a few different environmental sensors: a PMS5003 for particulate matter via UART, an SCD40 for CO2 and temperature/humidity via I²C, and an SGP40 for VOC readings—all driven by hand-configured UART, I²C, SPI, GPIO, and SysTick peripherals. To keep things robust against messy sensor data, I added frame header synchronization and CRC checksum validation to catch corrupted packets before they hit the display.

Everything is organized modularly with a clean separation between low-level drivers, data sharing, and the UI pipeline, rendering live metrics cleanly onto an ST7735 TFT display via SPI. It turned out to be a deeply rewarding dive into bare-metal development.

Personal Finance Tracker

As a semester-long project for a senior software engineering course, I co-developed a WPF desktop application for managing cash, savings, and brokerage accounts. I focused on the backend, integrating Firebase for authentication and cloud data storage, Alpha Vantage for stock searches and pricing, and LiveCharts2 for displaying financial data through graphs and charts.

I organized the project using MVVM and a layered architecture, separating views, view models, services, repositories, and models. This structure supported features including transaction tracking, budget monitoring, savings account management, and integration with external APIs.

Embedded DDA Raycaster

I wanted to write a program that could run on limited hardware, so I built a real-time 2.5D raycasting engine for an STM32 Nucleo microcontroller. Since the chip lacks a hardware floating-point unit, I used the DDA algorithm with Q16.16 fixed-point arithmetic and precomputed trigonometric lookup tables. The engine outputs graphics to an ST7735S display over SPI.

I organized the code into modular files (dda.c, player.c, map.c, and draw.c) for collision detection, camera rotation, and directional shading. I also built a cross-platform desktop companion version using SDL3 to experiment with higher resolutions and frame rates.

Task Scheduler

As part of a four-person team, I co-developed a cross-platform task and schedule manager. I focused on the backend, using SQLAlchemy, SQLite, and Pydantic for data management and validation. I implemented user authentication and authorization using Python security libraries and used FastAPI's dependency injection to manage database sessions and request-level dependencies.

Along with another team member, I developed REST API endpoints supporting task management, folder organization, search and filtering, and notification triggers.

Multithreaded HTTP Server

To learn more about network programming and concurrency, I built a multithreaded HTTP server in C++ using Winsock. Instead of creating a new thread for each connection, I implemented a worker-thread pool to handle multiple clients concurrently. I also implemented TCP socket setup, client connection management, HTTP request parsing and routing, and static file serving.

I tested the server with a PowerShell-based stress test that sent 10 waves of 50 concurrent requests. The server successfully handled all 500 requests without crashes.

DES File Encryptor

Wanting to learn more about user interface design and cryptography, I built a desktop file encryption application with an implementation of the Data Encryption Standard (DES) written from scratch. Instead of relying on an existing cryptography library, I implemented the core DES operations, including 16-round key scheduling, permutations, S-box substitutions, and the Feistel network.

I then added Cipher Block Chaining (CBC) mode with randomly generated IVs and PKCS#7 padding for block-based file processing. The application provides a desktop GUI with file selection, encryption and decryption modes, and validation for hexadecimal keys and file sizes.
